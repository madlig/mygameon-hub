## Rencana: Prompt ZCode-style untuk Gemini 3 Pro di Antigravity IDE

### Apa yang akan dibuat
File-file konfigurasi Antigravity IDE (`.agents/`) berisi prompt modular yang mereplikasi pola pikir dan cara kerja ZCode, ditulis dalam Bahasa Indonesia.

### Struktur File

```
.agents/
  agents.md                              ← Persona utama: ZCode-style Engineer
  skills/
    planning-methodology.md              ← Sistem 4 Fase Planning
    context-understanding.md             ← Pemahaman Konteks & Workspace
    coding-discipline.md                 ← Disiplin Coding & Referensi
    tool-usage-patterns.md               ← Pola Penggunaan Tool
    working-principles.md               ← Prinsip Kerja & Edge Cases
docs/
  gemini-zcode-prompt/
    README.md                            ← Panduan setup & optimasi Antigravity
    combined-prompt.md                   ← Versi gabungan (fallback/manual paste)
```

### 6 Modul Prompt

1. **Persona** (`agents.md`) — Identitas, filosofi kerja metodis, kehati-hatian, prefer existing patterns
2. **Planning** (`skills/planning-methodology.md`) — 4 fase (Understanding → Design → Review → Execute), parallel exploration, TodoWrite tracking
3. **Konteks** (`skills/context-understanding.md`) — Baca workspace instructions, git awareness, pattern matching, tech stack detection
4. **Coding** (`skills/coding-discipline.md`) — Referensi `file:line`, edit > write, match existing style/naming/comments
5. **Tools** (`skills/tool-usage-patterns.md`) — File read vs terminal vs browser agent, parallel calls, sub-agent delegation
6. **Prinsip** (`skills/working-principles.md`) — Report jujur, surface kontradiksi, reuse > create, anti-hedging

### Bonus
- `README.md` dengan panduan optimasi Antigravity IDE (terminal mode, strict mode, model selection, dll)
- `combined-prompt.md` sebagai versi gabungan yang bisa di-paste manual jika diperlukan

### Bahasa
Bahasa Indonesia, dengan terminology teknis dalam bahasa Inggris.

### Alasan menggunakan format `.agents/`
Antigravity IDE membaca konfigurasi dari `.agents/` secara native — tidak perlu copy-paste manual ke settings. Cukup buat file-nya dan Antigravity akan otomatis menggunakannya.
